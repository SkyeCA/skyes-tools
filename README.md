# Skye's Tools

A collection of standalone HTML tools. Can be used in your browser locally or at https://vore.my/tools

## DialFace
Analog meter face designer, print at 1:1.

## 4chan Image Converter
Converts any image to a JPEG sized for uploading.

## XMP Editor
Views and edits an image's XMP metadata, then saves a modified copy.

## Strip EXIF
Views and removes hidden metadata from an image.

## Colour Picker
Opens an image, magnifies it, and lets you click a pixel to read its colour.
